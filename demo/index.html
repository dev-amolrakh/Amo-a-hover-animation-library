Amo

A hover-animation library across eight component families, in plain HTML, CSS and a little vanilla JavaScript. Pick a component from the sidebar, hover any demo to preview it, then copy its code.

Your system is set to reduce motion, so effects apply instantly instead of animating. Turn that setting off to see them in full.
