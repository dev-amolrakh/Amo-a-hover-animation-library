# Effect catalogue

The interactive demo is the authoritative visual catalogue. The current release contains these component families:

- Buttons: slide, expand, sweep, reveal, wipe, radial, ripple, wave, liquid, curtain, shutter, morph, gradient, glow, border, stripes, pixels, bubbles, spring, roll, arrow, orbit, coin, magnetic, iris, neon, skew, rings, icon reveal, crossfade, and more.
- Cards: lift, tilt, border draw, orbit, spotlight, zoom, panel, flip, fill, peel, arrow, stack, neighbor focus, accent bar, shine, color, glass, wobble, parallax, morph, Ken Burns, overlay reveal, and badge effects.
- Text: underline, highlight, fill, strike, spacing, stagger, wave, roll, focus, gradient, outline, glitch, scramble, shadow, weight, typewriter, flip, brackets, neon, skew, double underline, cycle, blur cascade, and 3D rotation.
- Icons: spin, bounce, wiggle, pop, fill, flip, pulse ring, morph, slide bounce, orbit dot, squash, rotate/fill, jump, and glow.
- Images: zoom, frame reveal, grayscale/color, blur, overlay, caption, shine, Ken Burns, tint, split, rotate/scale, frame, corner crop, and parallax.
- Navigation: underline, pill, arrow, color, weight, dot, slide, chevron, double underline, spacing, top bar, and grouped active indicator.
- Badges: invert, pop, shake, ring, remove icon, gradient, glow, slide, bounce, flip, jiggle, and ping.
- Lists: background slide, indent, border accent, arrow reveal, scale/shadow, checkbox highlight, lift, and text/icon color.
