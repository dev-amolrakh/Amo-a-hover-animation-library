# Security Policy

## Supported versions

Security fixes are applied to the latest published version of Amo.

## Reporting a vulnerability

Please do not publish an unpatched security issue as a public GitHub issue.

Use GitHub's private security advisory/reporting workflow for the repository when it is enabled. If private reporting is not available, contact the maintainer privately before disclosure.

Include:

- a description of the issue
- affected files or classes
- reproduction steps
- impact
- a suggested mitigation, if known
