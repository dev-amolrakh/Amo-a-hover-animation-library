# Changelog

All notable changes to Amo are documented here.

## [1.0.0] — 2026-09-23

### Added

- Initial public release.
- CSS-first hover animation library.
- Button, card, text, icon, image, navigation, badge, and list-item effect families.
- Interactive showcase with effect catalogues and copyable snippets.
- Optional JavaScript helpers for pointer-aware effects.
- Reduced-motion support.
